## ❌ Issues to Watch For

### If You See...

**No theme colors**
→ Check CourseThemeProvider is applied
→ Check browser cache
→ Check CSS file exists

**Components don't show**
→ Check console for errors
→ Verify component data in course
→ Check import paths

**Console has errors**
→ Red "cannot find module" errors
→ Type errors about case_study, etc.
→ These indicate a problem

**Layout broken on mobile**
→ Components overlap
→ Text unreadable
→ Buttons unreachable
→ This indicates responsive issue
