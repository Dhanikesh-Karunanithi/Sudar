# SudarNotes — First-session storyboard

Companion to [SUDAR_2_0_VISION.md](SUDAR_2_0_VISION.md). Prototype: Learn `/journey` (nav: **SudarNotes**).

---

## Scene 0 — Enter the workspace

**Learner** opens SudarNotes from the nav.  
**Sees:** **Living notebook** on the **left** (working memory strip + suggested/accepted cards); **docked Sudar** chat on the **right**. Starters appear in the chat empty state.  
**Feels:** One shared desk — materials beside the tutor — not a floating panel covering the lesson.

---

## Scene 1 — Goal (intake, not a roadmap)

**Sudar:** Clarifies aspiration + experience with 1–2 questions. **No** 5-step syllabus.  
**Canvas:** Working memory shows Goal + open questions. Zero web links.  
**System:** Session mode `intake`; Twin `learning_goals` updated when goal is clear.

---

## Scene 2 — Diagnostic (socratic)

**Sudar:** Probes what they already do / where they stall.  
**Learner:** Answers in conversation.  
**Canvas:** Gaps / known hints in working memory.  
**System:** Twin-shaped fields update: `known_concepts`, `struggles_with`.

---

## Scene 3 — One idea (teach + suggest)

**Sudar:** Teaches **one** idea with analogy.  
**Canvas:** Suggests a concept card — learner Accepts into their notebook.  
**Pedagogy state:** Moves toward check cadence.

---

## Scene 4 — Soft check

**Sudar:** Explain-it-back / apply / catch-the-error (conversational, not quiz vibes).  
**Learner:** Responds.  
**System:** Soft-check breadcrumb on Twin; mode may `replan`.

---

## Scene 5 — Replan

**Sudar:** Names what landed; picks next micro-goal.  
**End state:** Clear “next” cue — longitudinal, not one-and-done outline dump.

---

## Contrast beat (for demos)

| Same learner | Course Learn (1.x) | SudarNotes (2.0) |
|--------------|--------------------|------------------|
| Intent | Open assigned course | State a goal |
| Progress | Module checklist | Working memory + soft checks |
| Help | Floating tutor on content | Tutor *is* the session |
| Notebook | N/A | Suggested → accepted cards you own |
