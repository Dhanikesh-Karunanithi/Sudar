# Pilot protocol (template)

Use with one institutional partner when you are ready to collect evidence for a follow-on publication.

## 1. Objectives

Primary (pick one for v1):

- **O1**: Adoption — % of invited learners with ≥1 session in 4 weeks.
- **O2**: Engagement — median weekly active learning minutes; tutor opens per active learner.
- **O3**: Early proxy outcome — quiz score delta pre/post for a fixed set of modules (paired design).

## 2. Population and ethics

- N (learners), cohort description (role, region if relevant).
- Consent: org AI policy + learner consent where generative overlays apply (match product settings).
- Data minimisation: export only aggregates unless IRB/ethics allows row-level export.

## 3. Intervention

- Duration (e.g. 6–8 instructional weeks).
- What is enabled: which modalities, tutor nudges, paths, ALP (if LMS-hosted).

## 4. Instruments

- In-app events (already in `learning_events`) — define pilot-specific tags or module ids.
- Optional surveys at week 2 and end (3–5 questions).

## 5. Analysis plan

- Pre-registered primary metric (O1–O3).
- Pre-specify handling of dropouts and inactive users.
- Cost: fill [COST_WORKSHEET.md](./COST_WORKSHEET.md) for the same window.

## 6. Reporting

- Internal: dashboard + short memo.
- External: update `paper.tex` evaluation section with n, design, and limitations; cite pilot as “in progress” until results exist.
