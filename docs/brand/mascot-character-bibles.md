# Sudar Mascot Character Bibles (MVP)

## Purpose
Define ship-ready personas for Sudar's hero + first three companion characters so product, design, and copy stay consistent.

Illustration deliverables, filenames, and art direction: [mascot-illustration-spec.md](./mascot-illustration-spec.md).

## Hero Mascot: Sudar
- Role: Always-on guide across the learner journey.
- Core traits: calm, encouraging, observant, concise.
- Primary jobs:
  - orient the learner at the start of sessions
  - celebrate meaningful progress
  - reframe setbacks into next steps
- Forbidden behaviors:
  - guilt-based nudges
  - judgmental language
  - over-promising outcomes
- Tone profile:
  - default: concise, clear, non-technical
  - adaptive modes: calm, balanced, energetic
- Emotional states:
  - neutral, guiding, supportive, celebratory, concern
- Typical triggers:
  - dashboard load, tutor open, session return, milestone completion

## Companion: Focus
- Role: Helps learners start and sustain attention.
- Core traits: direct, motivating, practical.
- Primary jobs:
  - reduce start friction
  - suggest short actionable next step
- Forbidden behaviors:
  - frequent interruptions during active solving
  - pressure-heavy language
- Tone profile:
  - short momentum prompts with clear action verbs
- Emotional states:
  - neutral, ready, focused, celebrating
- Typical triggers:
  - inactivity before starting a module
  - return after pause
  - session start with low momentum

## Companion: Memory
- Role: Supports retrieval practice and recap.
- Core traits: structured, reassuring, pattern-aware.
- Primary jobs:
  - suggest quick recall checks
  - recap key points from recent learning
- Forbidden behaviors:
  - overwhelming long summaries
  - trivia overload unrelated to current goal
- Tone profile:
  - prompt-based: "Recall", "Connect", "Apply"
- Emotional states:
  - neutral, prompting, validating, celebrating
- Typical triggers:
  - post-module completion
  - repeated mistakes in same concept area
  - return after multi-day gap

## Companion: Confidence
- Role: Protects learner self-efficacy during struggle.
- Core traits: empathetic, non-judgmental, steady.
- Primary jobs:
  - normalize mistakes
  - reframe confusion as progress signal
- Forbidden behaviors:
  - sarcasm
  - comparison with other learners
- Tone profile:
  - supportive and concrete, never patronizing
- Emotional states:
  - neutral, supportive, stabilizing, celebrating
- Typical triggers:
  - incorrect attempts
  - repeated retries
  - low-confidence moments after difficult content

## MVP Interaction Rules
- High-touch, but frequency-capped per session.
- Learner can switch to hero-only mode any time.
- Color and icon are paired for every character to preserve accessibility.
