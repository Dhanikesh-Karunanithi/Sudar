# Sudar Brand Audit Baseline (v1)

## Purpose
This baseline synthesizes current product status, research grounding, and messaging state so all brand decisions are anchored in what is true today.

## What Is Stable and Strong
- Sudar has a clear mission: democratize high-quality personalized learning.
- The architecture is differentiated and coherent: Studio + Learn + Intelligence over a shared data layer.
- The AI tutor "Sudar" with longitudinal memory is a distinctive narrative asset.
- The Digital Learner Twin concept connects product design, research framing, and market differentiation.
- The ALP plugin layer creates an expansion path beyond direct platform replacement.

## Research-Backed Claims We Can Use Confidently
- Sudar is evidence-informed and maps capabilities to adaptive learning, dual coding, retrieval practice, and intelligent tutoring literature.
- The platform addresses a well-known market gap: most LMS products remain largely one-size-fits-all and stateless.
- Architectural contributions in the LAMP paper can be used as positioning proof points:
  - LAMP reference platform
  - ALP plugin architecture
  - economic accessibility framing

## Claims That Need Scope Discipline
- Efficacy claims should not imply controlled trial outcomes yet (pilot is planned).
- Modality claims in public messaging should match the current product state and roadmap phasing.
- Cost messaging should include context and assumptions when using precise numbers.

## Messaging Gaps Identified
- Current marketing language mixes visionary and shipped claims without an explicit taxonomy.
- Visual identity guidance is currently fragmented and tied to older color assumptions.
- Product, pitch, and marketing documents are directionally aligned but not fully normalized to one brand voice and proof hierarchy.

## Visual System Gaps Identified
- No canonical design-token reference for light and dark parity.
- No single logo usage system tying narrative (equal sign -> S flow -> AI flame) to rules.
- No codified typography stack for premium-minimal brand expression at scale.

## Strategic Decisions Locked in This Cycle
- Positioning: balanced (speed + evidence + longitudinal tutor memory).
- Audience: mixed B2B (L&D + HR) for the next 90 days.
- Visual tone: premium-minimal + warm-human.
- Palette: Option A (Indigo + Ember), dual-theme parity.
- Typography: Manrope (headlines) + Inter (UI/body).

## Claims Taxonomy for All Brand Outputs
- Validated product claims: currently shipped capabilities and documented architecture.
- Evidence-informed claims: capability rationale grounded in learning-science references.
- Future-work claims: pilot, connector maturity, and roadmap items framed explicitly as planned.

## Implication for Brand Execution
Brand assets should make Sudar feel premium and trustworthy while remaining human and accessible, with proof-led messaging that is ambitious but claim-safe.

## Mascot Execution Baseline (MVP)
- Launch model: one always-on hero (`Sudar`) plus 3 human-like companions (`Focus`, `Memory`, `Confidence`).
- Product controls: learner-selectable intensity and hero-only mode to avoid over-interruption.
- First surfaces: dashboard and tutor chat; inline lesson appearances in follow-up phase.
- Measurement readiness: mascot impressions, interactions, dismissals, mode changes, and nudge outcomes tracked via learning events.
- Guardrail fit: non-manipulative copy, privacy-safe dialogue, culture-neutral language.
