# Fluency Metrics Glossary (Cursor Education Portfolio)

These metrics define success for the portfolio path and model what Cursor Product Education Engineering should measure—beyond completion rates.

| Metric | Definition | Proxy in this portfolio |
|--------|------------|-------------------------|
| **Activation** | Learner completes first guided mission with Chat + Terminal (not read-only) | M01 / A01 / E01 pass |
| **Agent depth** | Multi-step mission involving Editor + Agent + Terminal | M03, M07 |
| **Editorial judgment** | Learner rejects unsafe agent output | M06 defects caught |
| **Org fluency design** | Leader replaces vanity KPI with fluency set | A04 pass |
| **Launch coupling** | Education DoD includes tutorial + path update + deprecate note | E02 pass |
| **Lifecycle hygiene** | Deprecation leaves no orphan learner path | E04 pass |
| **Path fluency score** | Weighted mission score across courses | SCORM `cmi.core.score.raw` (≥70 pass) |

**Anti-metrics (do not optimize alone):** video watch %, quiz completion without lab, time-on-page without action.
