**Sudar Studio** is where your organisation authors courses, manages users, configures AI keys, and operates compliance views. Learners never author here, they live in **Sudar Learn**, which reads from the same database tenant.

Typical sidebar areas you will use weekly:

- **Content**: Dashboard, Courses, Learning Paths, Analytics, Training compliance.
- **Organization**: Users, Sudar Agents, Governance, Integrations, AI & API Keys, Org settings, and the **Sudar Help Center** link that mirrors this documentation set.

Sudar Agents are **bounded automations** with database audit trails, not a second mascot chat. The tutor named Sudar stays in Learn.

Deep engineering context (schema, ports, roadmap) stays in `ECOSYSTEM.md`; this Help Center stays user-scoped.
